# 知识星球发帖助手

> 篝火出品 · 收录于篝火 App 应用区

扫码登录知识星球后，用 Markdown 写图文帖，确认后一篇篇发布，发布记录存本机，可 AI 配图。

> 截图里的星球、帖子和图片全部是虚构的「示例」。

## 风险与免责

- **知识星球没有公开的发帖接口。** 本工具在应用自带的窗口里打开知识星球网页版，借用网页版自己的接口发帖。平台一改版就可能失效，也有被平台判定为异常操作、限制账号的风险，请自行评估后使用，后果由使用者承担。
- 只做「一次发一篇、发前弹窗确认」。**不做定时发帖，不做批量发帖**，也请不要用它高频发帖。
- 登录状态只保存在本应用的窗口里，不读取、不同步你电脑上的浏览器；本工具不读取、不保存、不导出 Cookie，发帖请求都在该窗口的页面里发出。
- 发布记录只存标题、时间、链接、星球名，不保存平台返回的任何他人信息。
- AI 配图用的是你自己填的图像模型接口，费用和内容合规由你自己负责；密钥只保存在本机。
- 接口地址、字段和上传流程是按网页版现状整理的，**尚未在真实账号上完整联调**，各处「未核实」的说明见下文。

## 怎么用

1. 点「打开知识星球窗口」，在弹出的窗口里用知识星球 App 扫码登录。
2. 回到本应用，点「读取我的星球」，在下拉框里选要发到的星球。读不到时，先在知识星球窗口里点进那个星球，再点「使用窗口当前星球」。
3. 在「写帖」里用 Markdown 写正文，可切到「预览」看效果。正文发布时会转成纯文字：标题写成【标题】，列表写成「· 」，加粗、链接等标记去掉（链接写成「文字（地址）」）。
4. 加图片：点「添加图片」或把图片拖进窗口（png / jpg / gif / webp，每张不超过 10 MB）；也可以用左侧「AI 配图」生成，或用「信息图」把自己填的内容排成对比表、流程图。图片附在帖子后面，不能插在文字中间。
5. 点「发布…」，在确认框里核对星球、正文和图片数，再点「确认发布」。成功后草稿清空，「发布记录」里多一条，可点「打开」跳到帖子。
6. 发布出错时不会自动重试。如果提示「没有收到平台的回复，帖子有可能已经发出」，先到星球里确认，再决定要不要重发。

**AI 配图设置**：左侧「AI 配图」里填接口地址（写到 `/v1` 这一级）、密钥、模型名、图片尺寸。本工具向 `{接口地址}/images/generations` 发请求（OpenAI 图像接口格式），返回 `b64_json` 或图片地址都能处理。不内置任何接口和密钥。

**排查**：平台改版后发帖失败时，打开左侧「排查」里的开关，再重试一次，可以看到知识星球窗口发出的请求的方法、路径和状态码（不含内容和登录信息），用来判断是哪一步的接口变了。

## 验收用例

以下 1～4 不需要登录，在应用里就能验证；5 需要真实账号，作者尚未联调。

1. 打开应用，在「写帖」里粘贴 `samples/示例-草稿.md` 的内容。编辑框右上角应显示「155 字」；点「预览」能看到标题、引用、加粗、列表；发布确认框里的正文应以 `【示例：手作新手的第一份工具清单】` 开头，列表行以「· 」开头。
2. 展开「信息图」，选「对比表」，标题填「示例」，内容粘贴 `samples/示例-对比表.txt`，点「生成并加入图片」。图片区应多一张三列四行的表。再选「流程图」，粘贴 `samples/示例-流程.txt`，应得到三步带箭头的流程图。
3. 展开「AI 配图」，不填任何设置时「生成并加入图片」是灰的；填好你自己的接口、密钥、模型名并写一句描述，应加入一张生成的图片。接口报错时提示里能看到状态码和原因，不含密钥。
4. 在未选星球时，「发布…」按钮是灰的；选了星球并写了正文后，点它会弹出确认框，点「再改改」不会发出任何请求。
5. （需要真实账号）登录后点「读取我的星球」应列出你的星球；选一个自己的测试星球，发一篇带一张图的帖子，应提示「已发布」，「发布记录」多一条，且只有标题、时间、链接、星球名。

`pnpm test` 里的 37 个测试用 `samples/` 下按已知接口结构编造的响应，在假的页面环境里运行注入脚本，验证星球列表、图片上传、发帖请求体（17 位编号原样发出）以及回传里不含他人信息。

## 自己编译

需要 Node.js 22、pnpm、Rust。

```bash
pnpm install
pnpm test          # 单元测试
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包
```

界面框架在 `src/kit`（所有 campfire-code 工具共用），本工具的逻辑在 `src/tool`。
